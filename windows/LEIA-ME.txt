ATALHO DO DITADO (Windows)

1. Copie esta pasta "windows" para o seu PC (ex.: C:\Ditado).
2. Abra Abrir-Ditado.bat no Bloco de Notas e cole sua chave Groq entre as aspas
   da linha:  set "GROQ_KEY="   (ex.: set "GROQ_KEY=gsk_abc123")
3. (Opcional) Copie config.exemplo.txt para config.txt e ajuste:
     SITE_URL = endereco do seu site publicado
     BROWSER  = chrome ou edge
4. Clique com o botao direito em Abrir-Ditado.vbs > Enviar para > Area de trabalho (criar atalho).
   Dica: no atalho, Propriedades > Alterar icone para escolher um icone.

O site abre em janela propria (sem barra de enderecos), com a chave ja
configurada e o motor "Groq Whisper" como padrao.
A chave fica apenas no seu PC. Nao envie o Abrir-Ditado.bat preenchido para o GitHub.
